# 暮刻：整體產品審視與升級摘要

2026 年 8 月 28 日

## 結論

暮刻最適合保持「一個安靜、私人、打開就能用的日常助手」，同時加入一個有學期節奏的校園模式。這次以 Unigent 作參考，吸收它最有用的課表、今天課堂、課室與功課資訊層級，但不加入帳戶、AI 或校園社群；個人資料繼續留在裝置內。

## 已完成的升級

- 首頁新增「今天摘要」，集中顯示未完成待辦、今日活動、今日工時／收入和健身狀態。
- 摘要直接提供「新增活動」和「補錄工時」，並顯示下一項活動。
- 工時可切換月份、查看該月全部記錄、編輯錯誤資料、刪除記錄及防止重複輸入。
- 月份收入、堂／節數與總工時會跟隨所選月份重新計算。
- 待辦可逐項刪除，亦可一鍵清除已完成項目。
- 資料管理新增持久儲存請求、上次備份時間和儲存空間錯誤提示。
- 支援的主畫面 Web App 會在 App 圖示顯示未完成／到期項目的徽章數量。
- 放大主要觸控按鈕並恢復頁面縮放，改善單手操作與可讀性。
- 通知和香港假期說明改為準確、可驗證的描述。
- 新增暮刻專屬的連結分享封面。
- 新增「每週課表」：輸入科目、星期、上／下課時間、課室及學期日期一次，整個學期自動排入月／週／日月曆。
- 新增「功課死線」：可記錄科目、作業、日期、時間、emoji 和顏色，完成、加入手機行事曆或刪除。
- 首頁新增「今日校園」小工具，集中顯示今天課堂、課室及到期功課；「下一項」亦會比較課堂、活動與死線。
- App 開啟時會發出「明日行程」摘要，按時間列出翌日課堂、活動與死線；功課另在死線前七天提醒。
- 可一次下載整份「暮刻校園行事曆」：課堂每週重複，課堂／活動提前一天、功課提前七天提醒，可配合 iPhone 日曆鎖屏小工具。
- 新增鎖屏預覽，讓使用者先看到下一堂課、今日死線與兩種通知的資訊層級。

## 為甚麼像 Unigent，但不是複製 Unigent

Unigent 官方資料把整學期課表、今日課堂與課室、功課／測驗／報告放在核心，並以鎖屏 Live Activity 顯示今天和下一堂課。這正好回應「不想每星期重打課堂」與「需要記住死線」的需求，因此暮刻採用相同的 today-first 原則，但保留原有酒紅、象牙與深色編輯感，也不加入社群或帳戶。[Unigent 官方網站](https://www.unigent.tw/) · [App Store](https://apps.apple.com/tw/app/unigent-%E5%A4%A7%E5%AD%B8%E7%94%9F%E6%A0%A1%E5%9C%92%E7%A4%BE%E7%BE%A4/id6757976384) · [Google Play](https://play.google.com/store/apps/details?hl=en_US&id=com.unigents.unigents)

Apple 的自訂鎖屏小工具需要以 Xcode 建立 Widget Extension；純網站不能直接交付相同的原生 widget。Apple 同時支援在鎖屏加入顯示即將到來活動的「日曆」小工具，所以暮刻採用不需帳戶、伺服器或 VPN 的實際方案：輸出 iCalendar，再由 iPhone 日曆呈現。[Apple WidgetKit](https://developer.apple.com/documentation/widgetkit/creating-a-widget-extension) · [Apple：加入 iPhone 小工具](https://support.apple.com/en-ie/118610)

iCalendar 的每週 `RRULE` 和 `VALARM` 可表達學期課堂及提前一天／七天警示。Web Push 在 iOS 主畫面 Web App 雖然可用，但關閉 App 後的排程推送仍需要遠端發送者；目前 GitHub Pages 是靜態網站，因此暮刻如實把「App 開啟時摘要」與「Apple 日曆可靠提醒」分開。[RFC 5545](https://www.rfc-editor.org/rfc/rfc5545.html) · [WebKit：iOS Web Push](https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/) · [WebKit：Declarative Web Push](https://webkit.org/blog/16535/meet-declarative-web-push/)

## 為甚麼這樣改

Apple 說明 iOS／iPadOS 16.4 起，加入主畫面的 Web App 可使用 Web Push，而通知權限必須由使用者的直接操作觸發；主畫面 Web App 亦可使用 Badging API。因此暮刻採用主動開啟通知和能力偵測的 App 徽章，不在不支援的瀏覽器硬性承諾。[Web Push](https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/) · [Badging](https://webkit.org/blog/14112/badging-for-home-screen-web-apps/)

本機瀏覽器資料通常先以 best-effort 模式儲存，網站可要求 persistent storage，但仍不能取代備份。因此資料管理同時提供持久儲存請求與 JSON 備份。[MDN：儲存配額與移除條件](https://developer.mozilla.org/en-US/docs/Web/API/Storage_API/Storage_quotas_and_eviction_criteria) · [MDN：`persist()`](https://developer.mozilla.org/en-US/docs/Web/API/StorageManager/persist)

觸控操作依照 WCAG 2.2 的目標尺寸原則放大，並移除禁止縮放的 viewport 設定，讓文字可以放大閱讀。[W3C：Target Size](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html) · [W3C：Resize Text](https://www.w3.org/WAI/WCAG21/Understanding/resize-text.html)

香港假期沿用政府 1823 的官方 iCalendar 資料；官方頁面目前列出 2025–2027 年的資料範圍，所以 App 亦如實標示這個年份範圍。[香港政府 1823](https://www.1823.gov.hk/tc/hong-kong-public-holidays-ical)

## 使用建議

1. 在 iPhone Safari 開啟暮刻，按分享，再選「加入主畫面」。
2. 第一次使用先到右上角「本機」開啟資料保護。
3. 每月或更換手機前下載一次備份。
4. 在「校園」輸入每週課堂與功課死線，再按「下載鎖屏行事曆」匯入 iPhone。
5. 長按 iPhone 鎖屏，選「自訂」並加入「日曆」小工具；通知權限亦需允許。

暮刻繼續不連接 ChatGPT、不需要登入，個人內容留在目前裝置的瀏覽器內。
